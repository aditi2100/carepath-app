# CarePath

CarePath is a safety-first, non-diagnostic care and health-resource navigator. It helps people organize symptoms, understand urgency signals, and choose a practical next step while making access constraints visible.

## Product highlights

- Explainable urgency bands with explicit emergency boundaries
- Constraint-aware routes for cost, transportation, language, and privacy
- Sample case for instant evaluation
- Local-first interaction: no account and no uploaded health data
- Responsive, accessible light aesthetic built with semantic HTML, CSS, and vanilla JavaScript

## Run locally

Open `index.html` in a browser. Use **Load sample case** to explore the full path, or select symptoms and constraints manually.

> This is a portfolio prototype, not medical advice. It does not diagnose or replace a qualified professional.
